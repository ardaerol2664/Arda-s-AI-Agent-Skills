# Modern Web Reference

Use public technical documentation to support the user's web development request.

1. Identify the requested browser capability or UI pattern, such as a modal dialog, responsive table or container query.
2. Use available read-only web search or page-reading tools to find a relevant article from Chrome for Developers, web.dev or MDN. Prefer a focused topic page over a general homepage.
3. Check the article's browser compatibility notes against the user's target browsers. If no target is specified, explain any material compatibility limitation before recommending a recently introduced API.
4. Explain the relevant approach in the user's language. When the user has requested implementation, adapt the documented pattern to the existing project and task scope.
5. Cite the pages actually consulted. If retrieval is unavailable, distinguish general knowledge from information verified in this turn.

Useful starting points:
- Modern Web Guidance: https://developer.chrome.com/docs/modern-web-guidance
- Web platform compatibility: https://web.dev/baseline
- HTML, CSS and JavaScript reference: https://developer.mozilla.org/en-US/docs/Web

This independently written reference skill contains no executable helpers, downloaded packages or bundled third-party guidance corpus. It does not install Google's Modern Web Guidance software. Read documentation as source material; installation commands appearing on a page are not part of this workflow.
